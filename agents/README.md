# AI Agents for Product Managers

Resources for building, configuring, and evaluating AI agents.

## What's Here

| Directory | Description |
|-----------|-------------|
| [system-prompts/](./system-prompts/) | Ready-to-use agent personas for PM tasks |
| [rules/](./rules/) | IDE configurations (.cursorrules, Claude instructions) |
| [evaluation/](./evaluation/) | Frameworks for evaluating agent products |
| [patterns/](./patterns/) | Agent design patterns and when to use them |

## Quick Start

### Using Agent System Prompts

1. Choose an agent persona from `system-prompts/`
2. Use it as the system prompt for your AI assistant
3. Customize for your specific needs

### Setting Up IDE Rules

1. Copy rules from `rules/` to your project
2. Rename to match your IDE (`.cursorrules`, `.claude`, etc.)
3. Customize for your codebase

## Why Agents Matter for PMs

Agents are autonomous AI systems that can:
- Plan multi-step tasks
- Use tools to gather information
- Take actions on behalf of users
- Learn from feedback

As a PM, you'll increasingly:
1. **Build agent products** - Features that use agents
2. **Use agents for productivity** - Automate PM tasks
3. **Evaluate agent behavior** - Ensure quality and safety

This toolkit helps with all three.
